# V7 Phase 6 Calm Operator UX

## Purpose

The admin is a calm routing operations platform, not a metrics cockpit.

## Core UX Rule

Show:

- state;
- impact;
- cause;
- safe next action.

Hide until drill-down:

- raw telemetry;
- command output;
- long metric tables;
- deep routing internals.

## Visual Rules

Use:

- restrained colors;
- semantic status tones;
- compact summaries;
- stable layouts;
- clear action hierarchy.

Avoid:

- blinking panels;
- noisy metric walls;
- oversized dashboards;
- topology spaghetti;
- protocol-centered navigation.

## Operator Trust

Every important status must answer:

- what is happening;
- who is affected;
- why it matters;
- what is safe to do;
- whether rollback exists.
