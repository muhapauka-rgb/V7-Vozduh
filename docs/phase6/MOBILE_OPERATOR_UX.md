# V7 Phase 6 Mobile Operator UX

## Purpose

Operators should be able to understand and perform simple safe actions from mobile.

## Mobile Rules

- no giant fixed tables;
- cards and summaries before detail;
- horizontal overflow only in drill-down tables;
- sticky critical status;
- action buttons must fit labels;
- drawers must be usable on small screens.

## Mobile Priority Actions

- view incidents;
- check affected users;
- inspect degraded channel;
- create/revoke profile link;
- run read-only diagnostics;
- enable safe mode.

## Current Risk

The embedded admin already has many responsive rules, but large tables and dense workspace panels remain scaling risks.

Future extraction should convert primary mobile workflows into compact task cards.
