# V7 Phase 6A Visual Noise Reduction

## Purpose

The admin should remain calm, compact, and readable as observability grows.

## Reduce

- extra borders;
- heavy separators;
- oversized status widgets;
- dense status grids;
- excessive typography variants;
- repeated warning colors;
- full-width telemetry tables on overview;
- decorative network diagrams.

## Keep

- restrained semantic colors;
- compact cards;
- stable spacing;
- predictable drawers;
- short labels;
- quiet empty states;
- clear primary actions.

## Status Color Rule

Status color is for state, not decoration.

Warnings and bad states should be visible but not visually loud unless the operator must act now.

## Density Rule

If a section needs more than one table or more than eight primary rows, it should become:

- summary;
- filtered detail;
- optional deep diagnostics.
