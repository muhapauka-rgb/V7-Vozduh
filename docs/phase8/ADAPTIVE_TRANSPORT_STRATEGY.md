# V7 Phase 8 Adaptive Transport Strategy

## Purpose

Prefer speed and stability, escalate stealth only when needed, and gracefully fallback under blocking.

## Strategy Order

1. normal fast mode;
2. stable verified route;
3. elevated stealth for scoped blocking;
4. severe fallback only under strong evidence.

## Transport Selection Factors

- route class;
- service class;
- transport capability;
- survivability history;
- performance penalty;
- user/org policy;
- current health;
- quarantine/maintenance state.

## Fallback Rule

Fallback must be:

- scoped;
- bounded;
- explained;
- reversible;
- verified.

## No Permanent Heavy Mode

Heavy stealth is a recovery tool, not the default product experience.
