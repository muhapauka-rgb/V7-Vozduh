# V7 Phase 8 Calm Intelligence UX

## Purpose

Intelligence must reduce operator burden without turning the UI into an AI cockpit.

## Show

- grouped insights;
- confidence;
- impact;
- reason;
- safe next action;
- evidence summary.

## Hide Until Drill-Down

- score components;
- raw telemetry;
- detailed prediction windows;
- all historical samples;
- transport internals.

## Forbidden

- prediction wall;
- AI chat-style routing panel;
- blinking forecasts;
- raw model scores on overview;
- unexplained recommendations.

## IA Placement

Intelligence belongs under existing groups:

- Channels;
- Routing;
- Services;
- Users;
- Trusted RU;
- Autoswitch;
- Security;
- Provisioning.

It should not create a new primary navigation area by default.
