# V7 Phase 8 Long-Term Learning Foundation

## Purpose

Build memory through transparent summaries, not opaque ML.

## Memory Types

- transport history;
- degradation memory;
- regional behavior memory;
- route class survivability;
- service-specific survivability;
- quarantine and maintenance history;
- reconnect instability history.

## Storage Rule

Use bounded summaries:

- last hour;
- last day;
- last week;
- last month.

## Explanation Rule

Learning must remain inspectable.

If a score changes, the operator should know which summarized signals changed.

## Boundary

Do not introduce opaque ML systems or self-modifying routing logic.
