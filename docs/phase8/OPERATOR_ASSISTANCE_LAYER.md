# V7 Phase 8 Operator Assistance Layer

## Purpose

Intelligence helps the operator, not replaces the operator.

## Assistance Examples

- `channel likely degrading`;
- `recommended quarantine review`;
- `observed Telegram instability`;
- `trusted RU quality falling`;
- `path MTU unstable`;
- `reconnect growth not correlated with egress degradation`;
- `service-specific degradation, avoid full reroute`.

## Assistance Contract

Each assistance item should show:

- status;
- impact;
- reason;
- confidence;
- safe next action;
- drill-down target.

## UI Rule

Assistance appears as grouped insights, not as an AI console or prediction wall.

## Operator Trust

The operator must always understand:

- what was observed;
- what is inferred;
- what the system will not do automatically.
