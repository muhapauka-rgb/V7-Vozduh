# V7 Phase 8 Preserve Deterministic Core

## Purpose

The routing core remains deterministic after Phase 8.

## Authoritative Layers

Policy:

- defines allowed behavior.

Route classes:

- define traffic categories and safety expectations.

Kill switch:

- enforces no-leak guarantees.

Lifecycle:

- prevents unverified production egress.

Autoswitch:

- applies bounded stability preservation only when gates pass.

Intelligence:

- recommends, scores, forecasts, and explains.

## Rule

Intelligence is advisory unless a separate deterministic workflow consumes it with explicit gates, audit, and rollback.
