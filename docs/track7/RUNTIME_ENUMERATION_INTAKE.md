# V7 Track 7.4 — Runtime Enumeration Intake

Track 7.4 requires authoritative live runtime evidence before anonymous lineage gaps can be converted into named governed runtime inventory.

## Required Evidence

Preferred command on the VPS:

```bash
cd /path/to/repo
tools/v7-runtime-tool-enumerate --references > runtime-enumeration.json
tools/v7-runtime-tool-enumerate --references --pretty
```

Then validate governance locally or on the VPS:

```bash
tools/v7-runtime-repo-diff --runtime-enumeration runtime-enumeration.json --pretty
```

## Acceptable Alternatives

If the repo is not present on the VPS, provide either:

- `runtime-enumeration.json` generated by `tools/v7-runtime-tool-enumerate`;
- a read-only copy of `/usr/local/bin/v7*`;
- a runtime manifest with per-tool basename, path, sha256, mode, size, mtime, and reference metadata.

## Not Allowed

Do not use Track 7.4 to:

- import all runtime tools into git;
- sync VPS files into the repo;
- delete, archive, chmod, or chown runtime tools;
- restart services;
- change datapath, routing, autoswitch, Trusted RU, or Gosuslugi behavior.
