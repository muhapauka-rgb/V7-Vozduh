## Notes

The E19 UI adds a compact Safe Action UX layer inside the Operator Approval Center. It uses the existing dark, calm card language and progressive disclosure drawers. It does not introduce a command console, a generic VPN button, or an execution CTA.

Operators can see:

- exactly which users and targets are in scope;
- why execution is disabled;
- what dual confirmation would require;
- what replay rejection checks must pass;
- how rollback and delayed monitoring are bound to future execution.
