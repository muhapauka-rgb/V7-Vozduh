# E26 Unproven Capabilities

The following remain explicitly unproven:

- Two-user governed movement.
- Larger cohort movement.
- Capacity-safe scaling beyond one user.
- Multi-user rollback.
- Semi-autonomous proposal generation.
- Autonomous governance.
- Large-scale execution.
- Fully movement-capable CLI packet consumer replacing approved raw fallback.
- Multi-target execution-target selection under simultaneous capacity pressure.
- Long-horizon delayed-movement monitoring beyond the E25.15 window.

## Boundary

E25 proves one-user operator-driven governed movement only. It should not be used as evidence that cohort execution, canary rollout, or autonomous movement is safe.
