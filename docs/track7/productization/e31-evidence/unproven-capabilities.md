# E31 Unproven Capabilities

The following capabilities remain explicitly unproven:

- 20-user execution
- 50-user execution
- 100-user execution
- Capacity-safe scaling above 10 users
- Large rollback sets above 10 users
- Large audit volumes above 10-user batches
- Large replay volumes and repeated packet denial at scale
- Multi-packet concurrency
- Concurrent rollback and forward workflows
- Semi-autonomous governance proposals
- Autonomous governance apply
- Production-pool execution
- Production-pool scheduling
- Batch transaction semantics
- Operator workflow UX and guardrails
- Policy-engine-driven target selection for production cohorts
