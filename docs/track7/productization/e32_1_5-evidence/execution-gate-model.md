## Capacity Gates

Forward movement requires these gates:

```text
GATE_CAPACITY_CERTIFIED
GATE_CAPACITY_FRESH
GATE_CAPACITY_CONFIDENCE
GATE_BATCH_WITHIN_EFFECTIVE_CAP
GATE_AVAILABLE_CAPACITY
GATE_TARGET_HARD_LIMIT
GATE_POLICY_CAP
GATE_TARGET_ELIGIBLE
```

## Full Gate Set

Capacity gates join existing governance gates:

```text
GATE_PACKET_VALID
GATE_PACKET_NON_EXPIRED
GATE_PACKET_NOT_REPLAYED
GATE_EXACT_USER_SET
GATE_EXACT_TARGET
GATE_ROLLBACK_MANIFEST
GATE_RUNTIME_HASHES_MATCH
GATE_READINESS_GO
GATE_RESTORE_SETTLE_GO
GATE_RUNTIME_CHECKERS_OK
GATE_SELECTED_MOVES_ZERO
GATE_HIDDEN_MOVERS_ABSENT
GATE_CAPACITY_CERTIFIED
GATE_BATCH_WITHIN_EFFECTIVE_CAP
```

## Denial Reasons

Capacity-related denial reasons:

- `DENY_CAPACITY_STATUS_NOT_CERTIFIED`
- `DENY_CAPACITY_STALE`
- `DENY_CAPACITY_EXPIRED`
- `DENY_CAPACITY_DEGRADED`
- `DENY_CAPACITY_CONFIDENCE_TOO_LOW`
- `DENY_BATCH_EXCEEDS_EFFECTIVE_CAP`
- `DENY_BATCH_EXCEEDS_AVAILABLE_CAPACITY`
- `DENY_TARGET_HARD_LIMIT_TOO_LOW`
- `DENY_POLICY_CAP_TOO_LOW`
- `DENY_TARGET_OCCUPIED_UNEXPECTEDLY`

## Fail-Closed Rule

If a capacity gate cannot be evaluated, it fails closed.
