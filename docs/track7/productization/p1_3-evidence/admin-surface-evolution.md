# P1.3 Admin Surface Evolution

admin_evolution_defined=true

## Current Admin

Current admin already has:

- `Главная`;
- `Пользователи`;
- `Каналы`;
- `Маршруты`;
- `Проверки`;
- `Безопасность`;
- `Настройки`;
- `Логи`;
- drawers;
- status pills;
- tables;
- workspace tabs.

## After Wave 1

New visible capability:

- EvidenceChip;
- EvidenceDrawer;
- EvidenceTimeline.

Visible in:

- `Главная`;
- `Проверки`;
- `Логи`;
- selected `Пользователи`, `Каналы`, `Маршруты` contexts.

Operator can inspect proof.

## After Wave 2

New visible capability:

- ProposalCard;
- ProposalStatus;
- ProposalDrawer.

Visible in:

- `Главная`;
- `Пользователи`;
- `Каналы`;
- `Маршруты`.

Operator can inspect recommendations and evidence links.

## After Wave 3

New visible capability:

- RuntimeTrustStatus;
- ReleaseTrustStatus;
- RuntimeTrustDrawer;
- ReleaseDrawer;
- RollbackAvailability.

Visible in:

- `Главная`;
- `Проверки`;
- `Безопасность`.

Operator can inspect whether runtime/release can be trusted.

## After Wave 4

New visible capability:

- search/filter;
- closure state;
- expiration/staleness indicators;
- role-gated advanced details.

Visible across all Phase 1 surfaces.

Operator can operate and audit the system sustainably.

## Evolution Verdict

Admin evolves by adding contextual proof, recommendation and trust surfaces to existing navigation. No new top-level sections are needed.
