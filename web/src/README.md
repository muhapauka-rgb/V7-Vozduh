# V7 Frontend Source Contract

Phase 6 scaffold only.

Target directories:

- `app`: app shell and route registration.
- `pages`: workflow-oriented screens.
- `components`: reusable operator UI.
- `layouts`: app frame, drawer, workspace layouts.
- `api`: wrappers for existing backend endpoints.
- `hooks`: polling and command state helpers.
- `stores`: UI and overview state.
- `styles`: design tokens and semantic status CSS.
- `utils`: formatting and severity mapping.
